How do I get a CSV of my supporters?

Google Contacts: contacts.google.com → select your supporters (or a label) → Export → Google CSV.

Mailchimp: Audience → All contacts → Export audience → download the CSV.

Excel / Sheets: one row per person, with a column for email (a name column helps) → File → Save as CSV.
